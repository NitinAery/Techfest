# MAGIC MASALA — Multi-Cuisine Restaurant & Tiffin Service
> **"Take a taste • Come join us. Life is so endlessly delicious."**
> **"What's on our Plate • Ghar Ka Khana near RGGEC Kangra"**

A modern, high-end restaurant web application inspired by award-winning UI/UX design (floating circular dish plates, clean elevated cards, modern typography, and intuitive ordering micro-interactions). Built for **Magic Masala**, situated at Massal Chowk, near Rajiv Gandhi Government Engineering College (RGGEC), Nagrota Bagwan, Kangra, Himachal Pradesh. Owned & operated by **Monika Rana**.

## 🎨 Design System & Video UI Breakdown

The entire interface has been redesigned based on the modern restaurant UI reference video:
1. **Hero Section ("Take a taste • Come join us. Life is so endlessly delicious"):**
   - High-contrast modern typography with subtle orange spice accents.
   - Modern floating showcase frame highlighting the authentic **Magic Masala** restaurant entrance photo with fairy lights, balloons, and dining room.
   - Floating review and pure-veg verification chips.
   - Price highlight: **₹1–200 per person** (Google Maps verified).

2. **"What's on our Plate" (Menu Showcase):**

   - Clean elevated cards featuring **large circular dish plates** that pop out.

## 🚀 How to Run Locally

```bash
# Start a local preview server
python3 -m http.server 4321

# Or with Node
npx serve .
```

Open [http://127.0.0.1:4321](http://127.0.0.1:4321) in any browser.
